# Assignment 1 匿名化学习摘要

## 学习目标

使用 C 语言的数组、字符串、函数和 typedef，完成一条文本检索流水线。

## 输入

- 查询词：命令行参数 argv[1] 到 argv[argc-1]
- 文本：始终从 stdin 逐行读取
- 最多保存 999 行，每行最多保存 80 个字符
- 超过限制的输入可以静默丢弃

## Stage 1

把输入行保存到数组，输出：

- 平均行长度，两位小数
- 第一行及其长度
- 最后一行及其长度

行号从 0 开始。C 字符串需要额外一格保存反斜杠零结束标记。

## Stage 2

固定行中每个字符位置 i，分别与所有查询词做大小写不敏感的连续前缀匹配，取最大长度 l_i。

整行分数：

    S = sum over i of (2 ^ min(l_i, 10) - 1)

这里的数学乘方不能直接写成 C 的 ^；^ 在 C 中是 bitwise XOR。

## Stage 3

输出最多五个最佳匹配：

1. 分数高者优先
2. 分数相同时，原始行号较小者优先

建议只排序行号索引，不搬动文本数组。

## 开发与测试

- 开发时可以使用 DEBUG
- 提交前必须设置 DEBUG 0
- 编译时启用 warning
- 使用 diff 做逐字符输出比较
- 测试大小写、部分前缀、同分、不足五行、80 字符边界和无末尾换行
